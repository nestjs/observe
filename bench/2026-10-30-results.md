# @nestjs/observe overhead, 30 October 2026

The run behind the [Overhead](../README.md#overhead) section of the main README, with `npm run bench` defaults. It measured the working tree of the `perf/span-overhead` branch on top of `143c2e2`, before those changes were committed, so the commit below names the base rather than the code measured.

SDK 0.3.20 (143c2e2), Node v24.20.0 on darwin arm64, Apple M1 Pro (10 cores, 32 GB), express adapter.
2 repetitions per configuration, interleaved; fixed-rate phases of 10s at 150 rps; saturation 10s with wrk, 64 connections; 3 boots per configuration, idle CPU over 5s of each.
Load average 12.09 9.27 7.76 at start, 3.75 5.78 6.75 at end.

Cells are the median across repetitions, with the range in brackets. A difference whose ranges overlap the baseline's is marked `~`. Event-loop delay is the lateness of a 10 ms timer.
